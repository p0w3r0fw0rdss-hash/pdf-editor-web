# PDF REAL FREE EDITOR

Suite completa de edición y herramientas PDF 100% gratuita y online. Funciona directamente en el navegador sin registro ni instalación.

## Herramientas incluidas

- **Editor**: texto, rectángulos, círculos, líneas, firma, resaltado y números de página con precisión milimétrica (coordenadas X/Y ajustables, opacidad, tamaño de fuente, color personalizado).
- **Fusionar**: combina múltiples PDFs.
- **Dividir**: extrae rangos de páginas.
- **Proteger**: añade contraseña (simulado).
- **Rotar**: gira páginas 90°, 180° o 270°.
- **Marca de agua**: texto con transparencia ajustable.

## Tecnología
- HTML5 + CSS3 + JavaScript
- PDF.js (Mozilla)
- Diseño tipo iLovePDF

## Uso
Abre `index.html` en tu navegador. No requiere servidor.
