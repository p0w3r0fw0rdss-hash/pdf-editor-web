# PDF Editor Online - Gratis

Editor de PDF 100% gratuito que funciona directamente en tu navegador. No requiere instalación ni registro.

## Funciones

- 📁 Subir archivos PDF
- ✏️ Añadir texto personalizado
- ✍️ Dibujar a mano alzada
- 🟡 Resaltar áreas
- 💾 Descargar el PDF editado

## Cómo usar

1. Abre `index.html` en tu navegador
2. Sube un archivo PDF
3. Usa las herramientas para editar
4. Descarga el resultado

## Tecnologías

- HTML5 + CSS3 + JavaScript
- PDF.js (Mozilla)
